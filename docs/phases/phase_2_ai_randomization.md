# 2차 개발: AI 및 도메인 무작위화

## 목표

사과와 환경 변화에 대응할 수 있도록 수확용 인식, 접근 계획 및 품질 모델의 일반화 성능을 높인다.

## 도메인 무작위화

- 사과 위치 및 크기
- 사과 표면, 착색, 손상, 윤택
- 조명, 배경 및 카메라 노이즈
- 가지와 잎의 배치
- 마찰 및 접촉 파라미터의 허용 범위

## 수확 인식

- Isaac Sim Replicator 데이터 생성
- OpenCV/YOLOv8 기반 사과 검출
- RGB-D 기반 3D 위치 계산
- 다중 사과 ID 도입
- 작은 가지와 잎 obstacle 추출

## 접근 및 파지

- 기본 `+Z` 접근 실패 시 다른 접근 각도 탐색
- 가지와 잎을 고려한 free-space 평가
- 사과 위치·크기 변화에 대한 파지 안정성 향상
- 필요 시 강화학습 적용

## 품질 분류

- 도메인 무작위화 데이터로 모델 학습
- 다중 프레임 결과 통합
- 실제 단위 크기·손상 면적 측정 고도화
- confidence 및 `RECHECK` 정책 확정

## 완료 기준

데이터셋 규모, 인식 정확도, 파지 성공률 및 평가 시나리오는 TBD다.

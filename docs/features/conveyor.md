# 컨베이어

## 공통 사양

- 모듈 수: 3개
- 모듈 길이: 각 0.5m
- 총 길이: 1.5m
- 모듈 사이 간격 목표: 5mm 이하
- 모듈 상면 높이 차 목표: 2mm 이하
- 모듈 중심선 오차 목표: 5mm 이하
- 유효 폭: 0.25~0.30m
- 측면 가이드 안쪽 폭: 0.14~0.16m
- 측면 가이드 높이: 40~60mm
- 롤러/벨트 상면 높이: 40~60mm
- 초기 명령 속도: 0.30m/s
- 검증 범위: 0.10~0.30m/s
- 최종 속도: TBD — 회전 및 촬영 시험 후 확정
- encoder 및 belt-state는 사용하지 않는다.
- 세 모듈 속도는 고정한다.

모든 사과는 rigid body와 collider를 가지며 컨베이어 및 다른 사과와 충돌한다.

## 컨베이어 1: 투입·안정화

- 형식: 평벨트
- 길이: 0.5m
- 로봇 투입 위치: 시작점에서 0.15~0.20m
- 투입 높이: 벨트 상면 위 30mm 이하
- 목표 투입 오차: 중심선 기준 좌우 ±30mm
- 역할: 낙하 충격 완화, 흔들림 감소, 검사 구간 진입 자세 안정화

## 컨베이어 2: 회전·촬영

- 형식: 롤러형
- 길이: 0.5m
- 실제 이송·촬영 유효 구간: 0.35~0.40m
- 진입·이탈 trigger collider 배치
- RGB 카메라와 영상 토픽은 상시 활성화
- bounding box 검출과 `apple_id` tracker를 상시 수행
- 검사 ROI 진입 시 프레임 수집 시작
- ROI 이탈 시 최종 등급 확정
- trigger collider는 검증 및 디버깅용으로 사용
- ID 유실·변경 시 `RECHECK`
- 후보 프레임 12장을 0.1초 간격으로 수집하고 대표 4~6장을 선택하는 안을 우선 사용한다.
- 정확한 후보/대표 프레임 수는 TBD다.
- 회전 합격 기준: 누적 360° 이상 또는 목표 관측 영역 확보
- 롤러 mesh는 우선 시각적으로 회전
- 이송은 collision surface의 surface velocity 사용
- 회전은 마찰계수와 angular damping으로 유도
- 회전 부족 시에만 검사 롤러에 revolute joint 적용
- 목표 검사 시간 2초와 0.30m/s 속도의 불일치 해결은 TBD다.

## 컨베이어 3: 가상 분류 검증

- 형식: 평벨트
- 사과 이동시간을 simulation time으로 측정
- 가상 푸셔 위치 3개 표시
- 위치 1: 진입점에서 0.10m
- 위치 2: 진입점에서 0.25m
- 위치 3: 진입점에서 0.40m
- 품질 결과와 예상 푸셔 위치 연결 확인
- MVP에서는 실제 prismatic joint 및 상자 분류를 구현하지 않는다.
- 컨베이어 2·3 진입은 trigger collider로 감지한다.
- 세 번째 푸셔와 모듈 출구 사이 안전거리는 TBD다.

## 시간

- ROS wall time이 아닌 Isaac Sim simulation time을 사용한다.
- 일시정지 시 모든 이송 timer도 정지한다.
- 실제 이동시간을 시험으로 측정하고 이론값과 비교한다.

```text
최소 투입 시간 간격 = max(
  로봇 수확시간 상위 95%,
  컨베이어 2 점유시간,
  분류 결과 산출시간 + 안전 여유시간
)

최소 중심 간격 = 컨베이어 속도 × 최소 투입 시간 간격
```

수확시간 P95 산출 방법과 안전 여유시간은 TBD다.

## 미확정 사항

- 최종 이송 속도
- 검사 시간 2초 확보 방식
- 마찰계수와 angular damping
- 사과 간 충돌, 정체 및 추월 처리 정책
- 품질 결과 지연 시 컨베이어 처리
- trigger 크기와 debounce 시간
